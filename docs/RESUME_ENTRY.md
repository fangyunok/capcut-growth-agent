# 简历项目表述（可直接精简使用）

**全球化增长内容 Agent（独立项目，基于 CapCut 官方公开资料）**

技术：Python、MCP、Qwen3-4B-Instruct、Ollama、Pydantic、Starlette、AutoDL RTX 3090

- 构建英/西双语 SEO 与社媒草稿 Agent：模型按 brief 自主调用 MCP 知识检索、编辑规则工具，应用校验工具参数、事实卡 ID、禁用短语与引用位置，输出包含来源链接、执行轨迹的人工审核包；证据不足时停止生成。
- 整理 16 条公开来源事实卡，设计 24 条双语流程评测并在 AutoDL GPU 上运行。引用对齐版本的回归结果为预期流程 21/24、应弃答请求 6/6；19 项自动化测试通过。评测仅覆盖流程与证据 ID，不代表人工事实正确率或业务增长。

面试时可现场演示：输入英语或西语 brief → Qwen 工具调用 → 草稿与来源映射 → 人工审核包；再输入无依据的配音效果承诺，展示拒绝生成。对于 3 条因引用位置不明确而返回 `needs_revision` 的西语样例，应主动说明护栏如何拦截，以及人工审核仍需做语义核查。
