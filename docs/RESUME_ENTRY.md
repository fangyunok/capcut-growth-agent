# 简历项目表述（v0.3.0）

**中英营销文案事实审校与视频合成 Agent｜独立项目**

技术：Python、Qwen 兼容接口、MCP、检索增强生成、Pydantic、Starlette、HTTPX、FFmpeg。

- 面向产品增长的发布前审校，设计“已有文案 → MCP 产品资料检索 → 问题定位与修订 → 来源对照 → 人工确认”流程；隔离产品及功能资料，缺证据停止修订，以确定性规则检查无来源数字、禁用措辞及引用位置。
- 实现人工确认与文案／资料快照 SHA256 绑定，防止使用旧审核结果；基于确认文本、用户图片／短片和字幕生成模板竖屏 MP4，保存分镜、字幕、合成日志并验证完整解码。
- 开发异步审校网页，支持有界后台任务、状态持久化、超时／中断记录；提供模型选工具与固定检索基线，以及 20 条中英回归用例，保留失败样本的统计分母。
- 完成 89 项自动化测试及真实 FFmpeg 渲染检查；示例数据随 wheel 打包，提供跨系统 CI 和离开源码目录的安装验证。

**上述测试不证明真实 Qwen 质量。**新版真实模型端到端运行与人工事实评审尚未完成，简历目前不填成功率、准确率、延迟降低或转化增长。若 CI 尚未实际跑完，描述为“配置跨系统 CI”，不要写“跨系统全部通过”。旧版 CapCut 生成的指标也不能套用。

面试演示顺序：介绍一个夸大营销主张 → 展示资料隔离和缺证据处理 → 说明程序校验的语义边界 → 展示确认版本及视频产物 → 解释 Agent 相对固定检索的开销与尚待验证的价值。
